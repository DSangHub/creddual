# Creddual

Rewards platform for debit card users.

- `frontend/` — React (CRA) + Tailwind app
- `backend/` — Node.js + Express + Prisma API (PostgreSQL)
- `docs/` — original design notes / code dumps

## Development

```bash
# backend
cd backend && npm install && npx prisma migrate dev && npm start

# frontend
cd frontend && npm install && npm start
```
